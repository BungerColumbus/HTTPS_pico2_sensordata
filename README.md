# README
This was for the CBL in second year. The purpose of this code is the following. We have the website and the pico2 w. The pico can connect to the internet (that's what the W inside of it stands for). 
It gathers data and stores it in a data structure that is later on sent to the website. The website awaits said data and changes whenever it receives new one.
The data contains a bunch of float numbers but also a .wav file.
After it sent the data it goes to sleep and wakes up, doing the same thing after around 10 seconds.
